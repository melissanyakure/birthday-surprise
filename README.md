# 🎂 Birthday Surprise

An interactive birthday website made with HTML, CSS and JavaScript, inspired by a birthday template I saw on Instagram Reels.

🔗 **Live site:** https://melissanyakure.github.io/birthday-surprise/

## ✨ Features

- 🔒 Passcode lock screen with a keypad
- 💌 "Do you wanna see it?" Yes / No screen
- 🎉 Happy Birthday screen with a photo frame and confetti
- 📸 "Memories" gallery in a search-engine style
- 💬 A personal birthday letter
- 🧸 Virtual hug screen with two animated crochet-style animals
- 🎶 A song link to finish

## 🛠️ Built with

- HTML5
- CSS3 (animations, grid, responsive design)
- Vanilla JavaScript (no libraries)
